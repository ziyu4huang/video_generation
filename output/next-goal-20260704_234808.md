# Removed: jucesharp/rpiv npm Extensions (todo + ask-user-question)

## What they were

Both packages come from the [rpiv-mono](https://github.com/juicesharp/rpiv-mono) monorepo by **juicesharp** — a collection of Pi Agent extensions with rich TUI (interactive terminal dialog) features.

### 1. `@juicesharp/rpiv-todo` — `todo` tool + `/todos` command + overlay

- Registered in **global** `~/.pi/agent/settings.json` (`packages`).
- Provides a task-list management tool (`todo`) with 4-state machine (pending → in_progress → completed → deleted tombstone), `blockedBy` dependency tracking, cycle detection, branch replay that survives `/reload` and conversation compaction.
- Adds a **live overlay** above the editor showing the model's current plan.
- Localized UI via `@juicesharp/rpiv-i18n` (8 bundled locales).
- **Sole source** — the `todo` tool is **NOT built into pi-agent**. pi-core only provides: bash, edit, edit-diff, find, grep, ls, read, write. The `todo` tool exists **exclusively** through this rpiv npm package.

### 2. `@juicesharp/rpiv-ask-user-question` — `ask_user_question` tool

- Registered as an **npmExtension** in `bun-apps/pi-agent/run-dir/manifest.json`, also a dependency in `bun-apps/pi-agent/package.json`.
- Provides a structured questionnaire dialog: multi-question tabs, multi-select checkboxes, side-by-side preview pane, per-option notes, submit review tab, free-text fallback.
- Built on `@juicesharp/rpiv-config` + optional `@juicesharp/rpiv-i18n` for localization.
- **Sole source** — the `ask_user_question` tool is **NOT built into pi-agent**. It exists **exclusively** through this rpiv npm package.

## Why remove

These tools are **NOT duplicated** by pi-core — they are the **only source** of `todo` and `ask_user_question` functionality. Reasoning for removal:

1. **User decision** — the user requested they be removed.
2. **Tool overlap / redundancy concern** (original assumption, now corrected): pi-core built-in tools are ONLY: bash, edit, edit-diff, find, grep, ls, read, write. Neither `todo` nor `ask_user_question` are among them.
3. **Context window tax** — both npm extensions add their schema + description to every API request (~1,037 tok for ask-user-question, ~485 tok for todo). If these tools are not actively used, this tax is pure overhead.
4. **Extra `node_modules` weight** — `rpiv-ask-user-question` pulls in `rpiv-config` as a dependency and occupies disk space

### Consequence

After removal, `todo` and `ask_user_question` tools will **no longer be available** in the next pi session. If needed later, they can be reinstalled with:

```bash
# todo
pi install npm:@juicesharp/rpiv-todo

# ask-user-question (as pi-agent workspace dep + manifest entry)
bun add @juicesharp/rpiv-ask-user-question
# then add to manifest.json npmExtensions
```

## Changes made

| Location | Change |
|---|---|
| `~/.pi/agent/settings.json` | Removed `"npm:@juicesharp/rpiv-todo"` from `packages` array (now empty `[]`) |
| `bun-apps/pi-agent/run-dir/manifest.json` | Removed `@juicesharp/rpiv-ask-user-question` from `npmExtensions` |
| `bun-apps/pi-agent/package.json` | Removed `@juicesharp/rpiv-ask-user-question` from `dependencies` |
| `bun.lock` | *(orphaned entries are inert — cleaner will tidy on next `bun install`)* |

## Remaining npm extension

Only `pi-web-access` (v0.13.0 by Nico Bailon) survives — it provides `web_search`, `fetch_content`, `get_search_content`, skills, PDF extraction, GitHub repo cloning, and YouTube/video understanding — **no built-in equivalent exists**.
