## Question

OpenViking's "sessions become memory" loop is the thing that beats native agent memory on LoCoMo: session commit → async summary + memory extraction → LLM dedup decisions (`skip/create/none` + per-item `merge/delete`) against similar existing memories → `memory_diff.json` audit trail.

kcard already has adjacent machinery: hermes journal ingest (`adaptHermesMarkdown`), distill gate/converge (adaptive threshold), `supersede.ts`, dictionary+LLM relation extractors. Questions:

- Is the loop: hermes journal (capture-only per context-lifecycle D1) → distill converge → **new** extraction pass producing typed cards with dedup-merge? Or does distill converge get upgraded to be the extraction loop?
- Dedup-merge: OpenViking asks an LLM `skip/create/merge/delete` per candidate against similar existing cards. kcard's dedup-first LeanRAG port is deterministic (frequency-vote). Which lane decides merge/delete — deterministic near-dup signal first (LeanRAG), LLM only on the ambiguous band? (Note leanrag-simplify D8 removed near-dup 0.3/signature mechanisms — don't resurrect them silently.)
- Audit trail: memory_diff equivalent — a per-run diff artifact (goes in vault as derived md? gitignored output/?).
- Async model: OpenViking queues on commit. kcard's trigger surface — on hermes distill converge, on-demand `zk_ingest` action, or a scheduled lane?

**D28 — distill converge IS the extraction loop; no separate second pass.** The hermes journal stays capture-only (context-lifecycle D1); the existing distill pipeline (gate → LLM enrich → converge → supersede) gains the typed contract (D17 registry), and the event writer is a stage of it. The raw hermes auto-converge lane (`session_shutdown` hook) stays as-is — it writes `hermes:*` upgrade-candidate cards that the curated path supersedes (mechanism B, `gate.ts` RAW_UPGRADE_PREFIXES). New `zk_ingest` action `extract` runs the whole loop in one call; `gate`/`converge`/`status` remain. Reason: OpenViking is single-commit extraction (not two passes); kcard's distill pipeline already IS gate→enrich→converge; a second pass would re-read the journal, duplicate enrichment cost, and need cross-pass card dedup.

**D29 — dedup lane = deterministic-first, LLM on the ambiguous band (OpenViking shape).** Deterministic layer: gate 0.72 Jaccard (in-batch + cross-vault kill/upgrade; a retained deliberate mechanism — NOT a leanrag-D8 resurrection), canonical-id upsert (ingest idempotency), mechanism-B supersede for raw targets, `add_only` passthrough per type. LLM merge/delete judgment only on the ambiguous band (an active curated same-relevant card surfaced as evidence; LLM chooses create/merge/delete/skip with a stated reason). **`event` (add_only) never merges/deletes — merge/delete votes are forced back to create** (a skip is still allowed). D8-near-dup mechanisms stay removed. Reason: measured OpenViking shape + D5/D6 (the LLM judgment is part of the extraction step, not a retrieval stage — retrieval determinism untouched).

**D30 — memory_diff equivalent = gitignored `output/kcard-extract/run-<ts>.json`** per-run artifact (the receipt precedent: `output/recall-audit/receipt-*.json`), carrying run metadata + per-entry decision (vote create/merge/delete/skip + reason + target) + writes + superseded + errors. NOT vault-derived md: D2 holds (vault md = canonical store; the diff is provenance, not knowledge — OpenViking keeps its diff in the archive, not the memory store).

**D31 — trigger = in-session on-demand (`zk_ingest` action=`extract`) + the existing `session_shutdown` auto-converge upgraded to drive extraction over fresh entries** — fresh-only via a persisted cursor (`.extract-state.json`, vault root — same pattern as `.distill-state.json`). NO scheduled/cron lane — charted-and-rejected (single-user local; the user's session cadence IS the queue; OpenViking's cursor + `.done`-marker queue machinery is server-multi-tenant-shaped, D1 out of scope). The shutdown hook stays best-effort + never blocks shutdown (existing silent-catch contract). `OB_HERMES_AUTOCONVERGE=0` keeps disabling the whole auto lane.
