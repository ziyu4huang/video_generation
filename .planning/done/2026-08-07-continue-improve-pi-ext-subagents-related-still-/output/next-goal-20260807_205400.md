## Footguns surfaced this effort (non-obvious, for the record)

- **Reserved keybindings:** `pi.registerShortcut` SILENTLY rejects Ctrl-O (reserved as `app.tools.expand`). The only path for a reserved key is the raw `ctx.ui.onTerminalInput`.
- **Docked widgets are never focusable:** input routes only to the single focused editor component. "Wire a key to the box" can't mean focus-the-box — it must be a global shortcut / onTerminalInput.
- **`consume:false` coexistence:** `onTerminalInput` runs BEFORE the focused component's keybinding path, so a non-consuming return lets the default action ALSO fire. That's how Ctrl-O toggles both the box AND the inline trace together.
- **Args are stringified-only:** `AgentHistoryEntry.text` for toolCalls is `JSON.stringify(args)` (the parsed object is discarded) and can be `... [truncated]` (breaking JSON.parse). Any arg-extraction must parse-tolerantly: JSON.parse → regex-scrape → fallback.
