## Question

Which SDD flow changes enter the spec? Candidates (from the skill's own stated frictions + 02's anatomy): fewer-but-bigger tasks (merge bite-sized steps into task-sized chunks), leaner task briefs (generated from plan slices vs hand-written), reviewer tier policy scaled to diff size, fix-loop batching (one fix wave per review round — the final-wave policy extended to task rounds), NEEDS_CONTEXT prevention (richer briefs vs pre-task context packets), parallel independent tasks via worktrees. Deliverable: prioritized change list with expected cost delta per change, justified against 02's numbers.

## Resolution

Decided (human grilling 2026-08-16): spec cut = the **five 02-quantified levers** (ledger enforcement and worktree parallelism deferred — stay prizes). Whole-branch final review stays mandatory in every case.
1. **Mechanical-task review drop** — plan tasks labeled `mechanical` (≤2 files, complete spec in the brief) skip the per-task reviewer dispatch; the whole-branch final review covers them. Expected ~200K × N saved (~2.4M at btw's 12-task scale). Guard: classification is stated in the plan task header; misclassification surfaces at final review.
2. **Plan-slice briefs** — task briefs generated by slicing the plan's task section verbatim, replacing hand-written prose with verbatim code (30× smaller; eliminates symbol-drift NEEDS_CONTEXT — one observed event wasted ~858K).
3. **One-fix-wave at task rounds** — every fix round batches ALL scoped findings into one fix dispatch + one scoped re-review (extends the final-wave policy to task rounds; one observed per-finding wave cost ~1.06M for a single finding).
4. **Mandatory pre-SDD plan review** — plan-critique pass before Task 1 (kills parked-minor plan re-litigation — ~15/21 of btw's parked minors were plan-mandated verbatim — and pivot-class contract violations; one observed reset --hard loss ~2.5M).
5. **Glue-task merge guidance** — writing-plans guidance merges small glue tasks (~1M per merged pair at observed scale).
