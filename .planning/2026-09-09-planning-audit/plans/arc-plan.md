## Decisions

- **D1 — Name is a content slug, not self-arc-N.** `2026-09-09-planning-audit`. The self-arc series is CLOSED (#2236); arc numbers are merge-time-claimed by parallel sessions (two same-day collisions documented in the arc-16 map); this effort is planning hygiene, not a self-develop round. - **D3 — Status vocabulary**: terminal = `done` | `complete`; non-terminal = `active` | `planning` | `designing` | `executing` | `in-progress` | `partial` | `paused` | `specified`; anything else = `unknown-token` red. `paused` counts as *acceptable resting state only with a dated note in the map body* (tool checks for a line matching `paused` + a 2026 date near it; heuristic, recorded as such).

Live-exempt list hardcoded + dated in the tool: `2026-09-09-self-arc-17`, `2026-09-09-self-arc-18` — with a comment that 18 arrives via open PR #2237.
- **D5 — Reconciliation criteria** (applies to every red row, in evidence order): (1) body/section cites merged PRs → flip to terminal, ensure Shipped-as/Resolution cites the *verified* numbers; (2) a later effort's map cross-links or content supersedes it → Resolution + `closed: (superseded)` + cross-links on both maps (except live-owned counterpart dirs — link on ours only, note the deferral); (3) no merged evidence, no supersession → `paused` + dated note naming what would reopen it; (4) live/recent → leave untouched, record as open row.
