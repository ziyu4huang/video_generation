### 關鍵教訓

| Lesson | Detail |
|--------|--------|
| **Always validate before write** | `validate-artifact` saved multiple write failures — discovered schema through iterative probing |
| **research_brief `existing_content`** | Not free-form; requires `{title, source, angle, what_it_covers}` — no `strengths`/`weaknesses`/`format` |
| **research_brief `misconceptions`** | Uses `myth` + `reality` + `source`, not `misconception` + `realty` + `correction_source` |
| **research_brief `underserved_gaps`** | Must be strings (not objects with `gap`/`why_open`) |
| **proposal_packet `narrative_structure`** | Tight enum: `[analogy, problem_solution, journey, debate, myth_busting, timeline, comparison, tutorial, story, data_narrative]` |
| **proposal_packet `render_runtime`** | Enum `[remotion, hyperframes, ffmpeg]` — `motion` not accepted (use `ffmpeg` for motion compositor) |
| **proposal_packet `line_items[]`** | Requires BOTH `tool` AND `operation` AND `estimated_usd` — and **no other fields** (`description`/`notes` cause "additional properties" errors) |
| **proposal_packet `production_plan.stages[]`** | Objects with `{stage, tools: [{tool_name, role, available}], approach}` — no free-form text |
